# Déposez vos pièces ici

Un dossier sans pièces n'est qu'une opinion. Tout ce que le cockpit affirmera
en séance doit s'appuyer sur un document que vous pouvez montrer.

## Les pièces qui font un dossier

- **le contrat de travail et tous ses avenants**, c'est la base contractuelle
- **les douze derniers bulletins de paie**, trois au minimum
- **la synthèse de votre dernier entretien annuel**, signée si possible
- **toute promesse écrite non tenue**, quelle qu'en soit la forme, courriel compris
- **la convention collective applicable**, si vous la connaissez

## Ensuite

Ouvrez Claude Code dans ce dossier et lancez `/demarrer`, ou dites simplement
« relis » pour traiter une pièce à la fois.

Les pièces exploitées passent dans `inbox/traites/`. **L'inbox doit toujours
finir vide**, c'est le signal qu'il ne reste rien en attente.

## Rien d'ici ne part nulle part

`inbox/` est exclu de git. Vos documents restent sur votre disque.
